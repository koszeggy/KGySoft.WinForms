! KGySoft.Libraries.Language namespace
======================================
! Every type in this namespace has been marked as obsolete. This is a legacy namespace from the old
  KGySoft.Language.dll dependency. The old translation mechanism doesn't translate anything anymore, just removes
  the possible distinction postfixes if present. To localize your application in a similar way with auto-generated
  resources, use the DynamicResourceManager class from the KGySoft.CoreLibraries package. For more details see:
  DynamicResourceManager class: https://docs.kgysoft.net/corelibraries/html/T_KGySoft_Resources_DynamicResourceManager.htm
  Application example: https://github.com/koszeggy/KGySoft.Drawing.Tools#localization

! Language class: It has been made obsolete. See the note above.
! ICustomTranslated interface: It has been made obsolete. See the note above.

! AdvancedButton class:
  ! Changing Standard classic (when there are no visual styles) and Popup FlatStyle rendering with images: just like
    the text, the image is also shifted when the button is pressed. This is how the native rendering also works.
  ! Default DisabledForeColor is SystemColors.GrayText rather than ControlDarkDark (when FlatStyle is Popup or Flat,
    or visual styles are not available).
  ! BackColor/ForeColor: when the control is not Enabled, they get/set the disabled colors. The Changed events are
    raised also when the Enabled state changes and the enabled/disabled colors are different.
  + New EnabledBackColor/EnabledForeColor properties: for symmetry with the existing DisabledBackColor and
    DisabledForeColor properties.
  + Making the overridden ForeColor/BackColor properties visible in the designer.
  + Supporting High DPI
  + New TextRenderingQuality property: brings back the functionality of the removed RenderingQuality property,
    but only for the text.
  + Focus rectangle width is OS and DPI dependent.
  + New AutoScaleFont property to allow automatic scaling of the font when the DPI changes even on platforms where
    this is not supported by default.

    original Button class as well. Classified as a fix rather than a breaking change as the issue is visual only.
