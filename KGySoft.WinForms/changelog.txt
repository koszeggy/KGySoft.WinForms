! v5.0.0:
~~~~~~~~~

NOTE: This is the first public version of KGySoft.WinForms (though the packages of the earlier versions have also
been made public since releasing the first preview of v5.0.0). This is the main reason for the large number of
breaking changes. Normally, KGy SOFT libraries do not contain such a large number of breaking changes, not even
in new major versions. But even if you happen to be using an earlier version of KGySoft.WinForms, the migration
to v5.0.0 should be relatively easy, as most of the breaking changes are just renames and obsoletions.

+ Assembly changes:
===================
+ Targeting also .NET Framework 4.7, .NET Core 3.1, .NET 5.0, 6.0, 9.0 and 10.0.

+ General changes:
==================
+ Making the library compatible with Mono and Wine.

! KGySoft.Libraries.Language namespace
======================================
! Every type in this namespace has been marked as obsolete. This is a legacy namespace from the old
  KGySoft.Language.dll dependency. The old translation mechanism doesn't translate anything anymore, just removes
  the possible distinction postfixes if present. To localize your application in a similar way with auto-generated
  resources, use the new LocalizationHelper class and/or the BaseForm.DynamicStringLocalization property in the
  KGySoft.WinForms namespace. As a low-level solution, you can also use the DynamicResourceManager class directly
  from the KGySoft.CoreLibraries package, along with its LanguageSettings class. For more details, see:
  - The example application using the new LocalizationHelper class: https://github.com/koszeggy/KGySoft.WinForms/tree/master/KGySoft.WinForms.Example
  - DynamicResourceManager class: https://koszeggy.github.io/docs/corelibraries/html/T_KGySoft_Resources_DynamicResourceManager.htm
  - LanguageSettings class: https://koszeggy.github.io/docs/corelibraries/html/T_KGySoft_LanguageSettings.htm

! Language class: It has been made obsolete. See the note above.
  ! The RedirectTranslate event has been removed. Use the LocalizationHelper.LocalizationRequested event instead.
  + The ActiveLanguage have been re-added for compatibility reasons (it was removed in v4.0.0).
! ICustomTranslated interface: It has been made obsolete. See the note above.
! The RedirectTranslateEventArgs class has been removed.

  CheckGroupBox class instead.

! KGySoft.WinForms.Forms namespace:
===================================
! The AdvancedMessageDialog class has been made obsolete. The dialog heavily relied on the obsoleted translation
  mechanism, and the built-in common dialog types can be replaced by the long existing TaskDialog class anyway.
! BaseForm class:
  ! The BaseToolTip field has been concealed by the EditorBrowsableState.Never attribute. Actually not a breaking
    change as the code referencing the field is still working, but the field is no longer visible in the IDE. Use
    the new ToolTip property instead.
  ! The default timings of BaseToolTip field (ToolTip property) have been changed.
  ! The CalledMdiChildClosed event is now obsolete. Use OwnedMdiChildClosed instead.
  ! The OnCalledMdiChildClosed method is now obsolete. Use OnOwnedMdiChildClosed instead.
  ! The PaintMdiClientArea event is now obsolete. Use the new MdiClient property instead.
  ! The default value of StartPosition has been changed back to WindowsDefaultLocation to match with regular Form.
    The previous default value was CenterScreen.
  + New MdiClient, OwnedMdiChildren, SuspendingMdiChild properties
  + New ToolTip property
  + Event subscriptions to self events are automatically removed when the form is disposed.
  + New CommandBindings property
  + New IsDesignMode property
  + New InvokeOnUIThread method: a safer and more convenient way to invoke a delegate on the UI thread.
  + New AutoScaleFont property to allow automatic scaling of the font when the DPI changes even on platforms where
    this is not supported by default.
  + New DeviceScale property
  + New DeviceScaleGetNewSize event: raised before the DPI changes, allowing to adjust the form size.
  + New DeviceScaleChanging event: raised when the DPI changes and the application is per-monitor DPI aware.
  + New DeviceScaleChanged event: raised when the DPI changes and the application is per-monitor DPI aware.
  + New DeviceScaleAutoResized event: raised when the form is resized automatically after the DPI change.
  + New IsLoaded property
  + New DynamicStringLocalization property and DynamicStringLocalizationChanged event
  + New ApplyResources and ApplyStringResources methods
  + Scaling the small icon of the form properly when the DPI changes.
  + Scaling the header text of the form properly when the DPI changes, even with per-monitor DPI awareness V1.
! DialogBaseForm class:
  ! The protected btnOk, and btnCancel fields have been replaced by read-only properties. The original
    members are still available, but they have been concealed by the EditorBrowsableState.Never attribute.
  ! The type of the pnlButtons member has been changed to OkCancelButtons (used to be TableLayoutPanel).
  ! The default value of StartPosition been changed back to WindowsDefaultLocation to match with regular Form. The
    previous default value was CenterScreen.
  + New ShowOKButton, ShowCancelButton and ShowApplyButton properties
! Dialogs class:
  ! The UseAdvancedDialogs property has been made obsolete. Use the new UseTaskDialogs property instead.
  ! InfoMessage(string)/WarningMessage(string)/ErrorMessage(string)/ConfirmMessage(string)/
    ConfirmMessage(bool,string) overloads: They no longer perform any translation, but expect the caller to use
    already localized strings.
  ! InfoMessage(string,object[])/WarningMessage(string,object[])/ErrorMessage(string,object[])/
    ConfirmMessage(string,object[])/ConfirmMessage(bool,string,object[]) overloads: They are now obsolete.
    They no longer perform any translation, just remove the possible distinction postfixes if present.
  ! InputDialog overloads: They no longer perform any translation, but expect the caller to use already localized
    strings. The default prompt value is taken from the assembly resources.
  + New InfoMessage/WarningMessage/ErrorMessage/ConfirmMessage overloads to provide an owner window.
  + New InputDialog overloads to provide an owner window.
  + The InputDialog overloads now support high DPI and per-monitor DPI awareness.
  + New CancellableConfirmMessage methods instead of the obsoleted DialogResult-returning ConfirmMessage overloads.
  + New UseTaskDialogs property: it allows to use the TaskDialog class instead of the standard MessageBox dialogs.
! The InputBox class has been removed (actually it was made internal as it was never meant to be public). Use the
  static Dialogs.InputDialog method overloads, which are the intended way to use input dialogs.
+ New DeviceScaleGetNewSizeEventArgs class
+ New DeviceScaleChangeEventArgs class
+ New OwnedMdiChildClosedEventArgs class
